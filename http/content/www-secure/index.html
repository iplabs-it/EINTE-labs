Secure HTTPS Server

You are connected via TLS (Transport Layer Security)

TLS Features Demonstrated

  • Self-signed certificate chain (CA → Server)
  • TLS 1.2 and TLS 1.3 support
  • Modern cipher suites (ECDHE, AES-GCM)
  • Subject Alternative Names (SAN)

Security Headers

This server sends these security headers:

Strict-Transport-Security (HSTS)
X-Content-Type-Options
X-Frame-Options
X-XSS-Protection

Commands to Explore

View certificate: openssl s_client -connect https-server:443 -showcerts

TLS handshake: openssl s_client -connect https-server:443 -state

Cipher info: openssl s_client -connect https-server:443 -cipher 'ALL'

Connection info: curl -k https://https-server/connection-info
