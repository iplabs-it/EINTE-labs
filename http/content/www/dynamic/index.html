Dynamic Content Section

Cache-Control: no-store, no-cache, must-revalidate

This content should never be cached. Every request should go to the origin server.

Use cases: Shopping carts, account balances, real-time data

How to verify:

Run: curl -I http://cache-proxy/dynamic/

Check the X-Cache-Status header - it should show BYPASS or MISS every time.

Server time: The server will add this dynamically in a real application.
