Welcome to the HTTP Lab

This server demonstrates various HTTP concepts including caching, content negotiation, and different HTTP methods.

Available Resources

  • Static content - Aggressive caching (immutable)
  • Dynamic content - No caching
  • Private content - Browser-only caching
  • Validated content - Must revalidate
  • News section - Short-lived cache with SWR
  • REST API - JSON responses

Lab Information
