Static Assets Directory

Cache-Control: public, max-age=31536000, immutable

Available Files

  • styles.css - Main stylesheet
  • tracker.js - JavaScript tracker
  • network-diagram.svg - Lab topology diagram

Caching Strategy

All files in this directory are served with aggressive caching headers:

  • max-age=31536000 - Cache for 1 year
  • immutable - Content never changes
  • public - Can be cached by proxies and CDNs

This strategy is ideal for versioned static assets where the filename changes when content changes.
