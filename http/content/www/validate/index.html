Validated Content Section

Cache-Control: no-cache

Important: no-cache does NOT mean "don't cache"!

It means: "Cache this, but always revalidate with the server before using."

Use cases: Content that must always be fresh but can use conditional requests

Validation Flow:

1. Client requests resource
2. Cache checks: "I have this, but must validate"
3. Cache sends: If-None-Match: "etag-value"
4. Server responds: 304 Not Modified (if unchanged)
5. Cache serves stored copy

How to test conditional requests:

Step 1 - Get the ETag: curl -I http://webserver/validate/

Step 2 - Use conditional request: curl -I -H "If-None-Match: your-etag" http://webserver/validate/

You should receive a 304 Not Modified response!
