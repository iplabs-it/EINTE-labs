Private Content Section

Simulated User-Specific Content
In a real application, this would contain personalized data.

Cache-Control: private, max-age=600

This content can be cached by the browser only, not by shared caches (CDNs, proxies).

Use cases: User profiles, personalized content, session data

How to verify:

Run: curl -I http://cache-proxy/private/

The proxy should show X-Cache-Status: MISS every time because it respects the private directive.
